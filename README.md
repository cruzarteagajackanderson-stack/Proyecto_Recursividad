# Proyecto de Recursividad

## Descripción
Proyecto desarrollado en Python para implementar y comprender el uso de funciones recursivas.

## Funciones implementadas
- Factorial.
- Potencia.
- Conteo recursivo de elementos en una lista.
- Sumatoria iterativa.
- Sumatoria recursiva.

## Ejecución
Para ejecutar el programa, utilizar el siguiente comando:

python recursividad.py

## Objetivo
Comprender el funcionamiento de la recursividad mediante casos base, casos recursivos y comparación con soluciones iterativas.
